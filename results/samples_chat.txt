### Write a Python function that checks whether a number is prime.
Here is a Python function that checks whether a number is prime:

```python
def is_prime(n):
    if n <= 1:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True
```

This function works by checking divisibility up to the square root of the number, which is a common optimization for prime checks. If the number is divisible by any of these values, it's not a prime number. If it's not divisible by any of these values, it's a prime number. The function then returns `False` for numbers less than or equal to the square root of the number.<|im_end|>
